Where should the controls live?

All three put the canvas edge to edge. They differ in how much stays on screen. Mockups show the inline-in-chat size with an edge picked; expanded gets more room but the same structure. Light theme here is only a placeholder; theme is the next question.

A

Floating cards + tool dock

Closest to Shapr3D. A Scene card (features, parts) floats at left, a slim dock of inspection tools (Section, Measure, Colors, Notes, Views, Motion) at right, each opening a small popover. Models live behind the project name pill. Panels collapse to the pill when space is tight.

B

Icon rails + drawers

Two thin icon rails (left: Models, Features, Parts; right: the inspection tools). Tapping an icon slides one drawer over the canvas edge; it closes on Escape or on canvas click. Less permanently on screen than A, but nothing is visible until opened.

C

Canvas only + one panel button

Nothing but the model, a name pill, the ViewCube and the selection bar. A single Panels button opens one tabbed sheet (Models, Features, Parts, Inspect, Export). Maximum model area when inline in chat; everything else is one extra click away.
